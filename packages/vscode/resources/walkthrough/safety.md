# You stay in control

- **Approvals**: file edits and commands wait for your OK, unless you switch on Autonomous.
- **Review hunks**: on any edit, click *Review hunks* to accept some changes and reject others.
- **Checkpoints**: restore your files to before any agent edit.
- **Modes**: Ask and Plan can read but never write.
- **Cost cap**: set `forge.maxCostUsd` to stop a run at a budget.
