# Go further

- **Specs**: turn an idea into requirements, design and tasks, then run each task.
- **MCP servers**: give the agent more tools (filesystem, git, browser, docs).
- **Skills**: reusable instructions that activate when they match your task.
- **Parallel agents**: several specialists work in separate git worktrees; you review and merge each branch.
- **Steering files**: project rules in `.forge/steering/` that shape every answer.
