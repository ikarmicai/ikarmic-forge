# Connect a model

Forge works with the model you already pay for. Pick one:

- **Anthropic, OpenAI, Google, OpenRouter, MiniMax**: paste an API key.
- **Azure OpenAI, Amazon Bedrock, Google Vertex**: use your cloud account.
- **Ollama, LM Studio, any OpenAI-compatible server**: run locally, no key.

Keys are stored in your operating system keychain (VS Code Secret Storage), never in settings files.

Click **Configure Provider** on the left to choose one.
